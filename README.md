## 一、这个仓库是做什么的

这是本人本学期《程序设计基础》课程的**个人作品集主仓库**，用于集中存放并版本化管理全学期 16 周的全部实验代码、实验报告与运行截图。

一句话理解：**它就像我的一本"会留下修改痕迹的电子实验笔记本"**——老师随时可以翻到任何一周，看到我当时写了什么、后来改了什么。

## 五、常用 Git 命令速查（新手向）

```bash
# 1. 看看现在改了哪些文件
git status

# 2. 把所有改动"装进箱子"（暂存）
git add .

# 3. 给这个箱子贴上说明标签（提交到本地仓库）
git commit -m "feat(week01): 完成环境搭建实验"

# 4. 把本地仓库同步到 GitHub（推送）
git push
```

## 六、提交信息规范

格式：`类型(范围): 简要说明`

| 类型 | 含义 | 示例 |
| :--------- | :--------------- | :----------------------------------------- |
| `feat` | 新增内容 | `feat(week05): 完成循环嵌套练习` |
| `fix` | 修复错误 | `fix(week08): 修正字符串反转的边界问题` |
| `docs` | 文档改动 | `docs: 补充第 10 周实验报告` |
| `style` | 格式调整 | `style: 统一缩进为 4 空格` |
| `refactor` | 重构代码 | `refactor(week12): 抽取公共父类` |
| `chore` | 杂项事务 | `chore: 更新 .gitignore` |
